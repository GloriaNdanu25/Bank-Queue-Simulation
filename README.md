# Bank Queue System Simulation (C++)

## Description
This project simulates a single-server bank queueing system for 100 customers using Discrete Event Simulation (DES).

## Input Parameters
* **Inter-Arrival Time (IAT):** Uniformly distributed between 1 and 5 minutes $U(1, 5)$.
* **Service Time:** Uniformly distributed between 1 and 6 minutes $U(1, 6)$.

## Key Outputs
* **Simulation Table:** Generates arrival, service start, service end, queue wait, and system times for 100 customers.
* **Performance Statistics:** Includes average queue waiting time, average service time, average time spent in the system, probability of customer waiting, and server utilization rate.
